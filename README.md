# nati-almeida.github.io
Meu site pessoal

## Exemplo de testes automatizados com Jest

O exemplo implementa soma, subtração, multiplicação e divisão em
`src/operacoes.js`, com os testes correspondentes em `tests/operacoes.test.js`.

Para instalar as dependências e executar os testes:

```bash
npm install
npm test
```
